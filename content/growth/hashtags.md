## Instagram SEO keywords (bio, name field, captions, alt text)
Instagram search is keyword-based, so put these words in plain text, not only hashtags.
- **Bio / name field:** strony internetowe, projektowanie stron, strona WWW, landing page, sklep WooCommerce, web designer, Polska.
- **Captions (first line):** use the phrase people search, e.g. "Ile kosztuje strona internetowa dla firmy?", "Strona dla barbera", "Strona dla kwiaciarni", "Redesign strony".
- **Alt text (every post, describe truthfully):** e.g. "Projekt strony internetowej dla barbershopu w Poznaniu, widok na telefonie". Never keyword-stuff.
- **Long-tail PL ideas:** strona internetowa dla małej firmy, tania ale dobra strona www, strona dla salonu fryzjerskiego, sklep internetowy WordPress cena, odświeżenie starej strony, strona szybka na telefonie.
- **EN:** website for small business Poland, freelance web designer Poland, landing page design, WooCommerce store setup.
- **Spoken keywords in reels:** say the main phrase in the first 5 seconds; add it as on-screen text and captions (also feeds search).
- Avoid: "najlepszy", "numer 1", "gwarantowane TOP Google" (compliance.md).

## Placement
- Hashtags in the first comment or at the end of the caption; keep captions PL first, EN below, tags once at the end (not duplicated per language).
- Don't repeat the same set on consecutive posts; rotate 3 variants per pillar.
- Test over 4 weeks and log reach per set in analytics; promote tags that bring non-follower reach.
