# Analytics Loop
Run in parallel (Sonnet): post-analyst, call-tracker, revenue-tracker, email-analyst. Then loop-feeder updates knowledge/content.md and writes reports/next-week.md. The orchestrator reviews and summarizes: 3 wins, 3 problems, 3 changes for next week.
