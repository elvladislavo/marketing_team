# Daily Run
Delegate to the **orchestrator** agent with this plan:
1. **Signal** (parallel, Sonnet): trend-spotter, comment-dm-agent (new comments/DMs), lead-catcher + lead-scorer.
2. **Create**: pick today's posts from knowledge/channels.md volume; post-writer / video-maker / graphic-designer / repurposer produce them; editor polishes.
3. **Approve**: approval-desk checks everything and fills queue/approval.md.
4. **Distribute**: scheduler + posters handle items already approved by the human.
5. **Nurture**: call-booker for hot leads, reminder for upcoming calls, newsletter on its day.
6. **Numbers**: post-analyst (and on Mondays: call-tracker, revenue-tracker, email-analyst, loop-feeder).
7. Write the morning brief (morning-brief skill).
