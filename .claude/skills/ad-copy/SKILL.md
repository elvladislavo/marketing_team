# Ad Copy

Inputs: platform(s), offer, audience, landing page, angle preferences.

Character limits:
| Platform | Field | Limit |
|---|---|---|
| Google RSA | Headline (up to 15) | 30 |
| Google RSA | Description (up to 4) | 90 |
| Meta | Primary text | ~125 visible |
| Meta | Headline | ~40 |
| LinkedIn | Intro text | ~150 visible |
| LinkedIn | Headline | 70 |
| TikTok | Ad text | 100 |

Write at least 3 variants per angle (pain, benefit, social proof, urgency/offer). Show the character count next to each line and never exceed limits. Add creative direction for image/video and an A/B test hypothesis. Save to `content/ads/`.
