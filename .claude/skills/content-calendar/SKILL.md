# Content Calendar

Inputs: period, channels, posting frequency, themes/campaigns, key dates (launches, holidays, events).

Steps:
1. Define 3-4 content pillars and the mix (e.g. 40% educational, 30% social proof, 20% product, 10% culture).
2. Anchor key dates first, then fill with pillar content; repurpose each hero piece across channels.
3. Output a Markdown table and a CSV at `deliverables/content/calendar-<period>.csv` with columns:
   `date, channel, pillar, format, title/hook, CTA, owner, status`
4. List the hero assets that need to be created first.
