# Brand Voice Guide

Interview the user briefly (or derive from provided materials/website): mission, audience, personality, competitors, words to use/avoid.

Write two files:
- `brand/voice.md`: brand personality (3-4 traits with "we are X, not Y"), tone by context (social, email, support, ads), vocabulary do/don't list, formatting rules (capitalization, emoji, Oxford comma), 2 before/after example rewrites.
- `brand/product-facts.md`: product description, features -> benefits, pricing, approved claims with sources, proof points (customers, stats), boilerplate.

All other agents read these files, so keep them accurate and mark unknowns `[TBD]`.
